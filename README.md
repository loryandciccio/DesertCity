# DesertCity

Computer Graphics project developed in Unreal Engine 5.5.4.

## Project Overview

This project is a cinematic walkthrough of a sci-fi desert city environment.

The work focuses on real-time computer graphics features such as lighting, dynamic shadows, reflections, atmospheric fog, post-processing and camera animation.

## Course Context

Project for the Computer Graphics course at Roma Tre University.

## Main Features

- Sci-fi desert city environment
- Sunset/golden-hour lighting setup
- Dynamic shadows
- Exponential Height Fog for desert atmospheric depth
- Post Process Volume for cinematic look
- Reflective water/cistern setup
- Custom reflective material: `M_Reflective_Water`
- Cinematic camera animation with Unreal Sequencer
- Final screencast showing the Unreal Engine editor

1. Open the project with Unreal Engine 5.5.4.
2. Open the project file: `DesertCity.uproject`.
3. Open the level: `L_showcase_level_Lorenzo`.
4. The cinematic sequence will be added in the next development step.
